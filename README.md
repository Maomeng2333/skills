## 怎么使用

在已连接 GitHub 的 Codex 中直接描述目标，例如：

- “帮我找小红书文案技能，先比较来源和用途。”
- “把刚选中的技能收录到我的 GitHub 技能库，并安装到 Codex。”
- “列出我的技能库，按分类查看；区分已收录和本机已安装。”
- “检查我选中的技能有没有新版本，说明变化后更新。”
- “帮我在 GitHub 找处理 Excel 的脚本，记录来源和使用方法。”

也可以显式调用 `$github-skill-library`；拆解任务并寻找技能组合时，调用 `$find-skills-combo`。安装目录中的技能会在下一轮对话可用；以届时实际发现的技能列表为准。

海报制作可直接调用 `$poster-workflow`，例如：“做一张课程招生海报，竖版，文案和素材按我提供的内容。”

## 收录和安装

收录时记录名称、用途、类型、分类、来源仓库、原始路径、版本或提交、许可证、登记日期和保存方式。普通文件和资料可以收录；只有符合当前客户端格式的技能才进入安装流程。

第三方资源默认保存原始链接与版本信息；需要保留副本时，先核实许可条件，保留完整依赖和原作者信息。技能运行所需的账号、服务或软件，在实际检查后单独记录。

GitHub 目录记录可在不同设备共享的资源信息。本机的安装路径、安装版本和验证结果保存在被 Git 忽略的 `local/installations.json`，避免把某一台电脑的状态误当成全部设备的状态。安装成功表示文件已落盘；实际调用验证另行记录。
