# 我的 GitHub 技能与文件库

用自然语言查找 GitHub 上的技能、脚本和资料，按用途收录到本仓库，再把选中的兼容技能安装到 Codex。

## 资源目录

| 名称 | 分类 | 类型 | 用途 | 保存方式 |
| --- | --- | --- | --- | --- |
| [GitHub 技能库管理](skills/github-skill-library/SKILL.md) | 效率工具 | 技能 | 查找资源、登记来源、维护本仓库，并安装或更新选中的 Codex 技能 | 本仓库原创 |

机器可读的完整登记表：[catalog.json](catalog.json)。分类采用标签，可使用：文案营销、图片设计、视频音频、办公表格、文档演示、程序开发、效率工具、其他。

## 怎么使用

在已连接 GitHub 的 Codex 中直接描述目标，例如：

- “帮我找小红书文案技能，先比较来源和用途。”
- “把刚选中的技能收录到我的 GitHub 技能库，并安装到 Codex。”
- “列出我的技能库，按分类查看；区分已收录和本机已安装。”
- “检查我选中的技能有没有新版本，说明变化后更新。”
- “帮我在 GitHub 找处理 Excel 的脚本，记录来源和使用方法。”

也可以显式调用 `$github-skill-library`。安装目录中的技能会在下一轮对话可用；以届时实际发现的技能列表为准。

## 收录和安装

收录时记录名称、用途、类型、分类、来源仓库、原始路径、版本或提交、许可证、登记日期和保存方式。普通文件和资料可以收录；只有符合当前客户端格式的技能才进入安装流程。

第三方资源默认保存原始链接与版本信息；需要保留副本时，先核实许可条件，保留完整依赖和原作者信息。技能运行所需的账号、服务或软件，在实际检查后单独记录。

GitHub 目录记录可在不同设备共享的资源信息。本机的安装路径、安装版本和验证结果保存在被 Git 忽略的 `local/installations.json`，避免把某一台电脑的状态误当成全部设备的状态。安装成功表示文件已落盘；实际调用验证另行记录。

## 当前内容

本仓库先提供管理技能。其他业务技能将在提出具体用途、完成筛选后加入。它依赖 Codex 已连接的 GitHub 工具，以及本机可用的技能安装入口，不会替代 GitHub 登录授权。
