# 海报类型与信息重点

按用户目的选用，不要求每张都包含全部模块。事实只采用用户素材或核实过的来源。

| 类型 | 优先信息 | 视觉重点 | 缺失事实处理 |
| --- | --- | --- | --- |
| 产品 / 促销 | 产品、已提供卖点、实际价格、活动条件 | 产品主体清晰，价格与条件相邻 | 无价格就做新品或产品介绍，不造优惠 |
| 活动 / 展览 / 演出 | 名称、时间、地点、参与方式 | 一个醒目主题，时间地点易查找 | 缺少关键日期地点则给草稿并列待补项 |
| 课程 / 讲座 | 主题、适合人群、可支持的内容、时间和报名信息 | 信息清楚，讲师照片或主题视觉按素材使用 | 不编资质、名额、收益承诺或讲师经历 |
| 招聘 / 招募 | 岗位、已提供条件、地点、联系方式 | 岗位与要求分区，文字完整 | 不猜薪酬和联系方式 |
| 节日 / 祝福 / 品牌 | 节日或主题、品牌祝语、Logo（如有） | 情绪和留白，文案克制 | 可创意补祝语；品牌和真实节日日期需有依据 |
| 公益 / 通知 / 信息图 | 核心信息、行动步骤、必要出处 | 可读性、层级和图示准确 | 无证据的统计数字省略；重要通知先保证原意 |
| 影视 / 阅读 / 创作 | 主题、用户素材、必要署名 | 主题意象与排版 | 用原创视觉方向；不编真实作者或获奖信息 |

用户未指定用途时默认竖版 3:4。横幅、方图、故事长图和打印尺寸属于不同版式，需要重新布局，不能仅拉伸原海报。

风格从主题与参考素材推导，例如：产品可用干净摄影、活动可用强图形、课程可用清楚的信息层级、节日可用主题插画。这些是可改的起点，不作为每类的固定限制。
